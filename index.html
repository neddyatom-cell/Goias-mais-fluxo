02 · Simulação de circulação

Demonstração esquemática: selecione uma rota e veja um trem percorrer o traçado ilustrativo. A geometria não corresponde à escala real do mapa.

Pronto para iniciar · animação ilustrativa

Como interpretar

O trem é um símbolo animado que percorre uma linha desenhada para demonstrar o conceito de circulação entre estações. Não é um horário operacional nem uma simulação de capacidade.

Rota ATraçado demonstrativo com uma conexão intermediária.

Para uma versão técnica, cada linha precisa ser redesenhada com pontos e ligações extraídos do projeto original.

O que esse número significa?

A porcentagem é calculada automaticamente a partir dos dois tempos selecionados. Ela só será uma estimativa realista quando os tempos forem sustentados por dados, como distância, velocidade média, paradas e condições de operação.

Não confunda redução matemática com economia de tempo comprovada. O resultado depende da qualidade dos valores de entrada.

04 · Transparência dos dados

O protótipo separa o que veio do material visual do que foi criado apenas para demonstrar as interações.

Informação de referência

A imagem do projeto enviada pelo autor está incorporada no site. Ela é a referência visual, mas o site ainda não extraiu automaticamente coordenadas, extensões ou especificações das linhas.

Valores de demonstração

Os 65 e 32 minutos são valores ilustrativos usados no comparador a partir do exemplo discutido. Precisam ser confirmados no documento e em estudo de viabilidade antes de serem apresentados como previsão real.

O que falta para validar tecnicamente

Geometria georreferenciada, distâncias por trecho, localização das estações, velocidade operacional, tempos de parada, demanda, integração com outros modais e análise de implantação.
